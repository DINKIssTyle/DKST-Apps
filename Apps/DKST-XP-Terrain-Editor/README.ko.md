# DKST XP Terrain Editor

[English](./README.md) · **한국어**

DKST XP Terrain Editor는 X-Plane의 Ortho 시너리를 탐색하고 지형 메시의 고도와 면 연결을 편집하는 데스크톱 앱입니다. 편집한 지형을 전체 타일의 Ortho4XP `.mesh`로 저장하거나, 기존 Ortho 시너리의 DSF에 반영할 수 있습니다. 이 문서는 0.17.0 소스의 한국어 UI를 기준으로 작성했습니다.

기존 Ortho 타일은 원본 `.mesh`·`.cfg` 없이도 DSF에서 편집 지형을 준비할 수 있습니다. `terrain`·`textures`는 기존 파일을 사용하며 CFG가 없으면 지형 형상에서 기본 강도 1의 노말을 계산합니다.

앱 이름을 **DKST XP Terrain Editor**로 변경했습니다. 기존 앱 식별자·설정·캐시 경로와 타일 내부 `dkst` 프로젝트 파일은 유지합니다.

**[사용자 매뉴얼](./user-guide.ko.md)**에서 첫 실행, 인앱 편집, OBJ 왕복, DSF 생성과 복구 절차를 확인할 수 있습니다.

## 주요 특징

| 기능 | 할 수 있는 작업 |
| --- | --- |
| 시너리 탐색 | X-Plane 라이브러리에서 Ortho 타일을 찾거나 작업 폴더를 직접 엽니다. 지도와 3D 뷰에서 작업 영역과 전체 타일을 확인합니다. |
| 3D 뷰 | 지형·영상·와이어프레임·수면 표시를 전환합니다. TOP·정투영·원근 보기와 Y축 배율로 작은 고도 차이를 살펴볼 수 있습니다. |
| 툴바와 입력 | 우클릭 메뉴에서 아이콘·텍스트 표시 방식을 바꾸고 버튼의 기능 설명을 툴팁으로 확인합니다. 숫자는 좌우 드래그·휠로 조절하며 단위는 Metric/US로 전환합니다. |
| 태양광·상위 시너리 미리보기 | 시간에 따른 태양광·그림자·지원 건물의 LM 야간 텍스처를 확인합니다. 상위 OBJ·FAC 건물은 거리와 LOD를 조절해 참고용으로 표시하며 지형 편집·저장에 영향을 주지 않습니다. |
| 정점·면 편집 | 브러시, 클릭, 사각형, 다각형으로 정점·변·면을 고릅니다. Z/X/C로 모드를 전환합니다. 고도 입력, 평탄화, Y축 핸들, 소프트 셀렉션으로 고도를 조절합니다. 선택 집합은 이름을 붙여 프로젝트에 저장할 수 있습니다. |
| 면 연결 편집 | 칼로 면을 나누고, 선택 면을 세분화하거나 N-gon으로 합칩니다. 영역 세분화는 같은 평면의 삼각형 연결 개선을 기본으로 사용합니다. |
| 노멀 선택과 베벨 | 실제 면 노멀 각도로 연결 영역을 선택하고, 선택 면의 외곽 또는 선택한 변 양쪽을 둥글게 만듭니다. 바닥과 벽 사이의 오목한 모서리와 정점 하나로 솟거나 패인 꼭짓점도 둥글게 처리합니다. 안쪽 100% 처리와 좁은 구간의 접속 폭 자동 조절을 지원합니다. |
| 선택 크기 기반 초기값 | 새 선택의 가로·세로 중 짧은 길이의 1/10으로 세분화 간격과 베벨 폭을 제안합니다. 같은 선택에서는 수동 입력값을 유지하며 Metric/US 표시를 지원합니다. |
| 지형 브러시 | 높낮이, 지형 고르기, 칠 도구로 넓은 지형을 조정합니다. 칠 도구는 먼저 마스크를 그리고 원하는 고도 작업을 나중에 적용합니다. |
| 런웨이 슬로프 | 화살표 방향으로 실제 지형 단면을 열고 거리와 고도를 선택한 m·ft 단위로 편집합니다. 레퍼런스 이미지, 소프트 브러시, 점 정렬, 단면 절단을 지원합니다. |
| 외부 도구 편집 | OBJ·MTL·텍스처를 내보내고 편집한 지형 OBJ를 원본 타일에 병합합니다. 병합 전에 OBJ를 검사하고 지원되는 오류의 복구 사본을 만들 수 있습니다. |
| DSF 생성과 백업 | 기존 DSF의 영상 재질·UV·수면 등 시너리 자원을 사용해 편집 지형을 반영합니다. 생성 결과를 검증한 뒤 DSF를 교체하고 이전 파일을 백업합니다. |
| 타일 단위 프로젝트 | 편집 상태, 복구 데이터, 내보낸 파일, 빌드 결과를 Ortho 타일 폴더 안의 `dkst`에 보관합니다. 타일 폴더를 다시 열어 작업을 이어갈 수 있습니다. |

## 작업 방식 선택

- 앱 안에서 고도나 면을 바로 고치려면 **인앱 편집**을 사용합니다.
- Blender 등에서 메시를 수정하려면 **외부 도구 편집**에서 OBJ를 내보냅니다.
- 시너리를 살펴보고 작업 영역만 정하려면 **탐색**을 사용합니다.
