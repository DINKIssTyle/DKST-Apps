# DKST X-Plane Ortho Editor 사용자 매뉴얼

[기능 소개](./README.ko.md) · [English user guide](./user-guide.en.md) · 기준 버전 0.17.0

## 1. 첫 작업 시작하기

1. **라이브러리**에서 X-Plane 시너리를 탐색하려면 환경설정에서 X-Plane 설치 폴더를 지정합니다. 원본 메시가 시너리와 다른 위치에 있다면 Ortho4XP 원본 폴더도 등록합니다.
2. 별도 타일로 작업하려면 **작업 폴더 → 작업 폴더 열기**에서 Ortho 타일 폴더를 선택합니다. 편집 데이터가 들어 있는 타일은 `dkst`를 포함한 타일 폴더 전체를 엽니다.
3. 왼쪽 목록에서 타일을 선택합니다. 지도에서 필요한 범위를 지정하고 **작업 영역**으로 보거나 **전체 타일**로 전환합니다.
4. **인앱 편집**을 열고 정점 또는 면을 선택합니다. 편집을 마치면 **저장**을 누릅니다. X-Plane에서 사용할 결과가 필요하면 **DSF 생성**까지 실행합니다.

Ortho4XP `.mesh`만 있는 폴더에서도 지형 편집과 Mesh 저장을 할 수 있습니다. 영상 표시와 DSF 생성에는 타일에 맞는 기존 시너리 자원이 필요합니다.

## 2. 화면과 카메라

| 컨트롤 | 동작 |
| --- | --- |
| **TOP** | 지형을 위에서 내려다봅니다. 활주로 방향이나 작업 경계를 확인할 때 사용합니다. |
| **정투영 / 원근법** | 정투영은 거리에 따른 크기 변화가 없고, 원근법은 앞뒤 깊이를 드러냅니다. |
| **Y축 배율** | 화면에서만 지형의 높낮이를 과장합니다. 표시만 확대하며 실제 고도와 저장 값은 바꾸지 않습니다. 라벨과 입력 단위는 **단위** 설정을 따릅니다. 되돌리기 아이콘으로 1×로 복원합니다. |
| **메시 / 텍스처 / 와이어프레임 / 수면** | 표시 레이어를 전환합니다. 텍스처를 끄면 지형의 주름이나 음영을 확인하기 쉽고, 와이어프레임은 면 연결을 보여 줍니다. |
| **선택에 맞춤** | 선택한 정점이나 면이 보기 안에 들어오도록 맞춥니다. 단축키는 `H`입니다. |

3D 뷰에서 우클릭 드래그는 시점을 회전하고, `Space`와 함께 드래그하면 화면을 이동합니다. 휠 확대·축소는 커서 아래 지점을 기준으로 합니다. 환경설정에서 커서 아래 메시 지점을 회전 중심으로 사용하거나, 그 동작을 선택 영역 위에서만 사용하도록 설정할 수 있습니다.

### 툴바 표시 방식

툴바 위에서 우클릭하면 다음 표시 방식을 선택할 수 있습니다.

| 메뉴 | 표시 |
| --- | --- |
| **Icons** | 아이콘만 표시합니다. 버튼에 커서를 올리면 이름과 기능을 확인할 수 있습니다. |
| **Icons with Text** | 아이콘과 텍스트를 나란히 표시합니다. 기본 방식입니다. |
| **Text** | 텍스트만 표시합니다. |
| **Text below Icons** | 아이콘 아래에 작은 텍스트를 표시합니다. |

선택한 방식은 장면·편집 툴바에 공통 적용되며 다음 실행에도 유지됩니다. **탐색 / 인앱 편집 / 외부 도구 편집**, **저장**, **다른 이름으로 저장** 등이 있는 상단 헤더는 이 설정의 적용 대상이 아닙니다. **Y축 이동 핸들**, **고도 라벨**, **정점 스냅**은 체크박스 대신 토글 버튼으로 표시하며 켜진 버튼은 파란 배경으로 구분합니다.

### 버튼 설명 툴팁

버튼 위에 커서를 약 **0.7초** 머무르면 첫 줄에 버튼명, 다음 줄에 해당 버튼의 기능 설명이 표시됩니다. 단축키가 있는 항목은 단축키도 확인할 수 있습니다. 툴팁이 한 번 나타난 뒤 다른 버튼으로 이동하면 즉시 전환되며, 버튼을 벗어난 뒤 **1초**가 지나면 다음 툴팁에 다시 0.7초 지연이 적용됩니다. 키보드로 버튼에 포커스를 옮기면 설명이 즉시 표시되며 `Esc`로 닫을 수 있습니다.

### 단위와 숫자 입력

**범위** 오른쪽의 **단위**에서 **Metric / US**를 선택하거나 `M`을 눌러 전환합니다. **Metric**은 m·m/s, **US**는 ft·ft/s로 거리·고도와 관련 속도를 표시하고 입력합니다. 단위 설정은 다음 실행에도 유지됩니다. 표시·입력 단위만 전환하며 내부 지형 좌표와 저장 데이터의 미터 기준은 유지됩니다. 원본 OBJ 좌표도 미터 기준입니다. 숫자를 입력하는 중에는 `M` 전환 단축키가 작동하지 않습니다.

고도, 소프트 셀렉션 범위, 브러시 지름, Y축 배율 등 숫자 입력칸에서는 직접 입력과 스핀 버튼 외에 다음 조작을 사용할 수 있습니다.

| 조작 | 동작 |
| --- | --- |
| 숫자 입력칸을 좌클릭한 채 좌우 드래그 | 왼쪽은 감소, 오른쪽은 증가 |
| 숫자 입력칸 위에서 휠 위 / 아래 | 증가 / 감소 |
| `Ctrl/Cmd`를 누른 채 드래그 또는 휠 | 해당 입력칸 증감 단위의 0.1배로 미세 조절 |
| `Shift`를 누른 채 드래그 또는 휠 | 해당 입력칸 증감 단위의 10배로 빠르게 조절 |
| 숫자 드래그 중 `Esc` | 드래그 시작 전 값으로 복원 |

값은 각 입력칸의 최소·최대 범위를 따릅니다. 단위를 US로 바꾸었다면 숫자 조절도 현재 보이는 ft 값을 기준으로 이루어집니다. 이 조작의 보조키는 뷰포트의 Y축 이동 핸들에 사용하는 고정 고도 간격과 별개입니다.

### 태양광과 상위 시너리

**표시 → 태양광**을 켜면 뷰포트 중앙 하단에 시간 슬라이더가 나타납니다. 시간을 움직여 지형과 건물의 태양 조명·그림자를 확인합니다. 지원되는 건물의 LM 야간 텍스처도 시간에 따라 표시됩니다. 조명과 시간은 미리보기 설정이며 지형 고도나 DSF 편집 결과를 바꾸지 않습니다.

뷰포트의 **상위 시너리** 카드를 열고 **상위 시너리 표시**를 켜면 해당 지역의 상위 시너리 OBJ·FAC 건물을 참고용으로 표시할 수 있습니다. 팩별 표시 여부, **렌더링 거리**, **LOD 품질**을 조절합니다. 비활성 시너리 팩은 표시 대상에서 제외되며, 라이브러리 팩의 자원은 배치된 건물을 해석하는 데 사용합니다. Type 2 FAC는 간략한 외형으로 표시될 수 있고, 표시할 수 없는 배치와 자원 문제는 카드에 안내됩니다. 상위 시너리는 표시 전용으로, 선택·지형 편집·Mesh 저장·DSF 생성 대상에 포함되지 않습니다.

## 3. 선택과 고도 편집

1. **모드**에서 **정점** 또는 **면**을 고릅니다. 면 고도 편집은 면을 구성하는 공유 정점을 움직이므로, 해당 정점을 공유하는 이웃 면도 함께 바뀝니다.
2. **선택** 도구에서 **브러시**, **사각**, **다각**, **클릭** 중 하나를 고릅니다. `Shift`로 추가하고 `Ctrl` 또는 `Cmd`로 제외할 수 있습니다. 브러시에서는 `[`·`]`로 크기를 조절합니다.
3. 다각형은 점을 세 개 이상 찍은 뒤 우클릭이나 `Enter`로 확정합니다. 시작점에 가까이 가서 스냅된 상태로 클릭해도 닫힙니다.
4. 속성 카드에서 고도를 지정하거나 **평탄화**로 선택 정점을 선택 고도의 중앙값에 맞춥니다. **고도 라벨**을 켜면 선택 범위의 동·서·남·북·중앙 고도를 확인할 수 있습니다.
5. **Y축 이동 핸들**을 켜고 녹색 화살표를 드래그해 고도를 조절합니다. `Ctrl`은 0.1m, `Shift`는 1m 단위로 움직입니다.
6. 주변도 부드럽게 움직이려면 속성 카드의 **소프트 셀렉션**을 켜고 영향 범위를 지정합니다. 직접 선택한 곳에서 멀어질수록 영향이 약해지며, 뷰포트에서 영향 범위를 확인할 수 있습니다.

선택 방식은 마지막 사용값을 기억하며, 기록이 없으면 **브러시**로 시작합니다. 정점·면 선택에는 가림 허용 선택이 항상 적용됩니다.

선택을 해제하려면 뷰포트 왼쪽 위 요약 카드 아래의 **선택 취소**를 누릅니다. 나중에 다시 쓸 선택은 오른쪽 **셀렉션 매니저**에서 이름을 붙여 저장합니다. 저장된 항목의 종류는 정점·면 아이콘으로 구분하며 다시 선택, 이름 변경, 선택 내용 갱신, 삭제가 가능합니다. 타일을 저장하면 셀렉션도 프로젝트에 포함됩니다.

## 4. 면 연결 편집

N-gon의 **삼각형으로 변환**은 경계·내부 정점의 좌표와 고도를 유지하면서 위에서 본 형태를 기준으로 내부 대각선을 최적화합니다. 고도가 다른 N-gon도 변환하며, 대각선 변경에 따라 면 사이의 고도 보간과 음영은 달라질 수 있습니다. 실행 취소로 원래 연결을 복원할 수 있습니다.

저장되는 Mesh에서는 어떤 면에서도 참조하지 않는 정점을 자동으로 제거합니다. 편집 중에는 실행 취소와 저장된 선택의 ID를 유지하기 위해 원래 정점 배열을 보관하되, 미사용 정점이나 화면용 면이 생성되지 않은 정점을 선택 핸들로 표시하지 않습니다. N-gon 내부 삼각분할에 실제로 사용되는 정점은 미사용 정점과 다르며 임의로 삭제하지 않습니다.

### 칼

기본 절단 결과는 **N-gon**입니다. 기존 삼각형의 내부 변을 넘어 하나의 면으로 다룰 수 있으며, 그린 칼선과 재질 경계는 유지합니다. 지형의 실제 높낮이와 DSF 출력용 삼각형 데이터는 보존됩니다. **정점 스냅** 옆의 **삼각형으로 자르기**를 켜면 절단 결과를 개별 삼각형으로 유지합니다. **정점 스냅**과 **삼각형으로 자르기**는 마지막 사용 상태를 저장하고 앱 재시작 후에도 복원합니다.

1. **칼**을 선택하고 뷰포트에서 절단 경로의 점을 차례로 클릭합니다. 점선과 교차점으로 다음 구간을 미리 봅니다.
2. 열린 절단선은 우클릭 또는 `Enter`로 확정합니다. 닫힌 경로는 점을 세 개 이상 찍고 시작점에 스냅된 상태에서 클릭합니다. `Esc`는 그리는 중인 경로를 취소합니다.
3. **정점 스냅**을 켜면 가까운 메시 정점을 절단 경로에 사용합니다. 시작점 스냅은 이 옵션과 별도로 항상 작동합니다.
4. 절단선이 앞선 구간과 교차하거나 겹쳐 빨간색으로 보이면 끝점을 옮깁니다. 절단 후 정점 모드에서는 경계 정점이 선택됩니다. 면 모드에서는 분할된 면이 기존 선택에서 빠집니다.

### 영역 세분화

1. **영역 세분화**를 열고 대상 면을 선택합니다. 사각형이나 다각형으로 고를 때도 세분화는 선택 면의 기존 경계를 따릅니다.
2. **정점 간격**을 현재 표시 단위로 입력하고 **세분화 미리보기**를 누릅니다. 파란 선은 바뀌는 연결, 주황색 선은 최소각이 15° 미만인 삼각형입니다.
3. **같은 평면의 삼각형 연결 개선**은 기본으로 켜져 있습니다. 베벨·브러시 자동 세분화와 같은 연결 개선 처리를 사용하며, 선택 영역의 평평한 부분에서 내부 대각선을 다시 배치합니다. 원래 고도 표면을 기준으로 세분화하며, 공유 변을 나눌 때는 이웃 면에도 같은 정점을 연결합니다.
4. 예상 정점과 삼각형 수를 확인하고 **세분화 적용**을 누릅니다. 적용 후에는 기존 선택 영역에서 나뉜 새 면들이 다시 선택됩니다. 공유 변 연결을 위해 함께 나뉜 이웃 면은 선택하지 않습니다. 적용은 한 번에 실행 취소할 수 있습니다. 보호 경계가 있는 구간은 목표 간격에 도달하기 어려울 수 있습니다.

베벨·브러시 자동 세분화와 영역 세분화는 같은 기본 세분화 처리를 공유합니다. 영역 세분화는 원래 면의 고도를 보간하며, 베벨은 세분화 후 전이 구간의 고도를 곡선 형태로 바꿉니다. **같은 평면의 삼각형 연결 개선**은 필요하면 끌 수 있습니다.

선택 면 세분화는 한 번에 새 정점 **65,536개**까지 추가할 수 있습니다. 한도를 넘으면 정점 간격을 늘리거나 선택 면을 나누어 작업합니다. 실시간 브러시의 자동 세분화는 스트로크당 **8,192개**로 별도 제한됩니다. 미리보기는 선택·범위·간격·연결 개선 설정이 바뀌면 무효화되며, 카메라 이동이나 표시 옵션 변경으로는 사라지지 않습니다.

### 선택 크기에 따른 초기값

**영역 세분화의 정점 간격**과 **베벨 폭**은 새로 선택한 정점·면의 실제 가로·세로 중 짧은 길이의 **1/10**으로 초기값을 추정합니다. 선택 범위의 수평 크기를 기준으로 하므로 고도 차이, 카메라 줌, Y축 배율은 계산에 영향을 주지 않습니다.

| 선택 범위의 크기 | 세분화 정점 간격 | 베벨 폭 |
| --- | --- | --- |
| 10 × 20m | 1m | 1m |
| 600 × 1,000m | 60m | 60m |
| 30,000 × 50,000m | 3,000m | 1,000m — 베벨 상한 적용 |

- **새 선택**으로 바꾸면 두 초기값을 다시 계산합니다. 같은 선택에서 도구나 카드를 닫았다 열 때는 직접 입력한 값을 유지합니다.
- 추정값은 미터 기준 0.1m 단위로 반올림합니다. **US**에서는 같은 실제 길이를 feet로 환산해 표시합니다.
- 세분화 간격은 0.1~100,000m 범위로 제한합니다. 베벨 폭의 자동 초기값은 0.4~1,000m 범위이며, 현재 분할 수 × 0.1m보다 작지 않게 조정합니다.
- 추정값은 시작점입니다. 원하는 정밀도에 맞춰 조절하고 미리보기의 추가 정점·삼각형 수를 확인합니다. 생성량 제한과 보호 경계 검사는 계속 적용됩니다.

### 노멀 경계 선택

**면 → 선택**의 **클릭** 오른쪽에서 **노멀 경계 선택**을 고릅니다. 브러시 크기 대신 **노멀 각도** 슬라이더가 나타납니다. 면 위에 커서를 올리면 선택될 연결 영역을 미리 보여주며, 클릭하면 선택합니다. Shift는 추가, Ctrl/Cmd는 선택에서 제외합니다.

인접한 두 면의 실제 기하 노멀 사이 각도가 설정값 이하이면 선택이 이어집니다. 각도를 낮추면 각진 경계에서 멈추고, 높이면 더 넓은 영역으로 확장됩니다. 클릭 후 각도를 바꾸면 같은 시작 면에서 선택을 다시 계산합니다. N-gon은 하나의 선택 단위이며 **Y축 스케일**과 화면 음영은 계산에 영향을 주지 않습니다. 마지막 각도는 재시작 후에도 기억합니다. 보호된 면과 작업 범위 밖의 면은 제외합니다.

### 베벨

면을 선택하고 속성 카드의 **평탄화** 아래 **베벨**을 엽니다. 선택 외곽 주변의 좁은 전이 구간을 둥글게 만드는 지형용 기능입니다. 전이 구간 안의 정점 고도는 바뀌며, 그 구간에 포함되지 않은 윗면과 주변 지형의 고도는 유지합니다.

| 설정 | 의미 |
| --- | --- |
| 베벨 폭 | 전이 구간의 기준 폭. 현재 단위(m/ft)로 입력합니다. |
| 안쪽 비율 | 선택 안쪽으로 들어갈 폭의 비율. 100%에서도 옆면의 실제 기울기에 맞춰 연결 접점을 확보해 모서리를 깎습니다. |
| 라운딩 | 0%는 직선 연결, 100%는 원래 모서리를 제어점으로 하는 단면 곡선입니다. |
| 분할 수 | 폭을 나눈 목표 정점 간격을 결정합니다. 높일수록 곡면이 촘촘해지고 생성 정점이 늘어납니다. |

솟아 있는 지형의 윗면 모서리를 처리하려면 다음 순서로 작업합니다.

1. **면** 모드에서 윗면을 선택합니다. **노멀 경계 선택**으로 옆면과 구분해서 고를 수 있습니다.
2. **베벨**을 열고 선택 크기로 제안된 폭을 확인합니다. 안쪽으로 깎으려면 **안쪽 비율 100%**에서 시작합니다.
3. **라운딩 100%**, **분할 수 4**에서 미리보기로 형태를 확인하고 필요에 따라 조절합니다. 안쪽 100%에서도 옆면 경사를 따라 연결 접점을 확보해 윗면 모서리를 둥글게 만듭니다.
4. 좁거나 오목한 구간은 접속 폭을 자동으로 줄입니다. 해당 구간의 실제 폭은 입력한 기준 폭보다 작아질 수 있습니다.

**베벨 미리보기**에서 파란 면과 와이어로 결과를, 주황 선으로 원래 선택 외곽을 확인합니다. 변경·추가 정점 수를 확인한 다음 **베벨 적용**을 누릅니다. 설정이나 선택이 바뀌면 다시 미리보기를 해야 합니다. 기울기 변화가 없어 변경될 정점이 없으면 적용할 수 없습니다.

수면·재질 경계, 열린 외곽, 보호 정점 및 작업 범위를 침범하는 결과는 적용하지 않습니다. 오목하거나 좁은 구간은 연결 가능한 범위까지 접속 폭을 자동으로 줄입니다. 이 기능은 지형의 공유 정점을 유지하며, 일반 입체 오브젝트의 모든 모서리를 자동으로 처리하는 기능은 아닙니다. 적용은 한 번의 실행 취소로 복원됩니다. 토폴로지가 바뀌므로 기존 칠하기 상태는 초기화됩니다. 저장과 DSF 출력에도 결과가 반영됩니다.

### N-gon과 정점 삭제

- 여러 인접 면을 선택하고 **선택 면 합치기 / N-gon 만들기**를 누르면 외곽을 유지하면서 내부 연결을 단순화합니다. 내부 정점이 사라지면 지형 형상도 달라질 수 있으므로 단면이나 와이어프레임을 확인합니다.
- **N-gon 전체 선택**을 누르거나 개별 N-gon을 고릅니다. 선택이 N-gon으로만 구성되면 **삼각형으로 변환**을 사용할 수 있습니다. 변환은 기존 정점을 사용하며, 같은 평면에서 삼각형이 한 꼭짓점에 몰리는 경우 내부 연결을 개선합니다. 정점 밀도를 높이려면 이어서 **영역 세분화**를 적용합니다.
- 정점 모드에서 **선택 정점 삭제 · 면 재연결**을 실행하면 선택한 내부 정점을 제거하고 주변 면을 다시 연결합니다. 작업 경계나 수면 접점 등 보호된 연결은 편집할 수 없습니다.

## 5. 지형 브러시

| 도구 | 사용법 |
| --- | --- |
| **높낮이** | 지름·경도·강도를 지정하고 지형 위를 드래그해 고도를 조절합니다. 고도 동작과 변화 속도는 옵션 카드에서 설정합니다. |
| **지형 고르기** | 주변 고도 차이를 부드럽게 연결합니다. 경사 전환부에서는 작은 강도로 시작해 와이어프레임과 음영을 함께 확인할 수 있습니다. |
| **칠** | 먼저 지형 위에 마스크를 칠하거나 지웁니다. 범위와 강도를 확인한 다음 고도 작업을 적용합니다. 큰 삼각형 내부에도 마스크를 칠할 수 있습니다. |

대상을 제한하려면 정점이나 면을 먼저 선택하고 브러시 옵션에서 선택에만 적용하도록 설정합니다. 고도 브러시의 자동 세분화는 브러시 자취 주변에 필요한 제어점을 추가합니다. 스트로크 도중 `Esc`를 누르면 진행 중인 변경이 취소됩니다.

## 6. 런웨이 슬로프

1. 단면으로 편집할 정점이나 면을 선택하고 **런웨이 슬로프**를 누릅니다.
2. 지형 위에서 시작점과 끝점을 클릭합니다. 화살표 방향을 확인하고 필요하면 **방향 뒤집기**를 누른 뒤 **단면 열기**를 선택합니다.
3. 단면은 시작점에서 끝점 순으로 왼쪽에서 오른쪽으로 표시합니다. 가로축은 거리, 세로축은 고도이며 **단위** 설정에 따라 m 또는 ft로 표시합니다.
4. 점이나 엣지를 상하로 드래그하거나 고도를 입력합니다. 빈 곳을 드래그하면 여러 점을 선택할 수 있고 `Shift`로 추가, `Ctrl/Cmd`로 제외합니다. **라인업 (정렬)**은 선택한 양 끝점의 고도를 기준으로 그 사이 점을 직선상에 배치합니다.
5. **소프트 브러시**는 반경 안의 단면을 가중치에 따라 상하로 움직입니다. 반경·경도·강도를 지정할 수 있습니다. 더 많은 제어점이 필요하면 단면의 **칼**로 원하는 거리에서 면을 나눕니다.
6. **레퍼런스 이미지**를 불러와 위치, 가로·세로 크기, 투명도를 조절할 수 있습니다. **두 점으로 보정**에서는 이미지의 두 점에 실제 거리·고도를 지정해 맞춥니다.
7. 변경 지형 미리보기를 확인하고 **고도 적용**을 누릅니다. 적용 전 취소하면 단면에서 만든 고도 변경과 절단이 폐기됩니다.

## 7. 저장, 프로젝트 보관, DSF 생성

**저장**은 편집 상태와 전체 타일의 Mesh 결과를 기록합니다. **다른 이름으로 저장**은 작업을 별도 Ortho 패키지로 분기할 때 사용합니다. 편집 결과를 옮기거나 보관하려면 시너리 리소스와 `dkst`를 포함해 Ortho 타일 폴더 전체를 복사합니다.

| 폴더 또는 파일 | 내용 |
| --- | --- |
| `dkst/project.json` | Ortho 패키지의 프로젝트 정보 |
| `dkst/tiles/<좌표>/source/` | 작업 기준 Mesh 및 해당하는 경우 기준 DSF |
| `dkst/tiles/<좌표>/saved/`, `recovery/` | 저장한 편집 상태 및 자동 복구 데이터 |
| `dkst/tiles/<좌표>/exports/`, `builds/` | OBJ 내보내기와 빌드 결과·보고서 |
| `dkst/tiles/<좌표>/backups/dsf/` | DSF 교체 전 백업 |

### 백업 보관 개수

**환경설정 → 백업 최대 개수**에서 1~1,000개로 설정합니다. 기본값은 **5개**입니다. 타일마다 Mesh 저장 백업과 DSF 백업에 각각 적용되며, 최신 백업부터 설정한 개수만 보관합니다. 설정 변경만으로 파일을 삭제하지 않고 다음 저장 또는 DSF 생성이 성공한 뒤 오래된 백업을 정리합니다. 현재 작업 파일, 기준 원본, 자동 복구 데이터와 직접 만든 별도 사본은 이 개수에 포함하지 않습니다. 백업 정리에 실패하면 저장 결과는 유지하고 완료 창에 경고를 표시합니다.

### X-Plane에 반영하기

1. **인앱 편집** 상단의 **DSF 생성**을 누릅니다. 원본 Ortho 시너리 폴더가 맞는지 확인합니다. Mesh 단독 작업이라면 해당 타일의 기존 DSF, `terrain`, `textures`, Ortho4XP cfg가 있는 폴더를 지정합니다.
2. 생성 중에는 상태와 진행률을 확인합니다. **생성 콘솔 로그**를 펼치면 상세 로그를 볼 수 있으며, 오류 발생 시 자동으로 펼쳐집니다. 완료 시 성공 상태와 실제 DSF·백업 경로가 표시됩니다. 긴 사용 안내는 **생성 안내**에서 확인하며 하단 버튼은 본문 스크롤과 별도로 유지됩니다. 생성한 DSF는 시너리의 `Earth nav data` 아래 정상 타일 파일명으로 반영됩니다.
3. X-Plane에서 시너리를 다시 로드해 편집한 구간을 확인합니다. 지형은 타일의 실제 편집 결과를 사용하며, 앱의 Y축 배율은 X-Plane에 전달되지 않습니다.

N-gon 삼각분할은 거의 일직선인 경계 정점끼리 가느다란 삼각형을 만드는 연결을 피하고, 외곽 정점과 고도는 유지합니다. 이미 삼각형으로 변환한 면이 DSF 좌표 전환 후 일직선으로 겹치면, 같은 재질의 인접 면과 내부 연결을 재분할해 복구합니다. 면을 버리거나 최종 연결 검증을 생략하지 않습니다.

DSF 생성 시 좌표 양자화로 가느다란 면이 뒤집히거나 사라지는 경우 저장 정밀도를 자동으로 높입니다. 편집·좌표 전환 중 생긴 극도로 가느다란 겹침은 같은 재질의 내부 대각선을 재연결해 복구합니다. 정점 위치·고도·외곽 경계는 유지하며, 콘솔에 자동 조정·복구 단계를 표시합니다. 재질 경계와 수면 경계를 넘는 재연결은 하지 않습니다. 최종 DSF는 공유 변·중복·틈 검증을 통과해야 저장됩니다.

이 기능은 기존 Ortho DSF를 기준으로 지형을 갱신합니다. 최초 DSF를 Mesh만으로 생성하거나 영상 다운로드, 새 해안선·수심 생성을 수행하는 경우에는 별도의 Ortho4XP 작업이 필요합니다.

### 빌드 오류 위치와 보고서

DSF 생성이 실패하면 오류 아래 **문제 위치로 이동**과 **보고서 생성** 버튼이 나타납니다. 문제 위치로 이동하면 기존 작업 영역을 줄이지 않고 카메라를 맞춥니다. 필요한 경우 기존 영역과 문제 좌표 주변 250m를 포함하도록 영역을 넓혀 주변 면도 편집할 수 있게 합니다. 타일 전체 보기 상태는 유지합니다. 위치를 확정할 수 없는 파일·설정 오류에서는 이동 버튼이 비활성화됩니다.

보고서는 현재 Ortho 폴더의 `dkst/tiles/<좌표>/reports/`에 ZIP으로 생성됩니다. 오류 단계·좌표·면적·정점 정보, 빌드 로그, 편집 기록 및 실패 당시 원본·편집 후·DSF 입력 메시의 주변 부분(JSON·OBJ)을 포함합니다. 메시 부분은 문제 영역 주변 100m, 각 4,096면까지이며 잘린 경우 JSON에 표시됩니다. 전체 시너리나 텍스처는 포함하지 않습니다. 이후 편집을 계속해도 실패 당시 자료를 사용합니다. 생성한 ZIP을 개발자에게 전달하세요. 자동 전송되지 않으며, 로그와 편집 정보에 로컬 경로가 포함될 수 있습니다.

### 백업에서 다시 시작하기

오른쪽 **DSF 백업**에서 현재 DSF 또는 이전 백업을 고르고 **선택한 DSF로 편집**을 누릅니다. 앱은 선택한 버전의 실제 지형을 기준으로 엽니다. 그 상태에서 DSF를 생성하면 현재 정상 DSF가 새로 백업되고 편집 결과가 정상 파일명에 반영됩니다.

## 8. 외부 도구에서 OBJ 편집하기

1. **외부 도구 편집**에서 작업 영역을 정한 다음 **OBJ로 내보내기**를 실행합니다. 여러 타일을 내보냈다면 편집할 타일의 OBJ를 확인합니다.
2. Blender 등에서 지형 OBJ를 엽니다. 좌표는 로컬 미터 단위이고 X는 동쪽, Y는 위쪽, Z는 남쪽입니다. 원점과 배율을 유지하며, 내보낸 `project.json`, MTL, 텍스처 및 기준 파일의 상대 경로를 유지합니다.
3. 지형 OBJ를 편집합니다. 패치 외곽의 보호 정점은 위치와 높이를 유지하고, 수면 경계와 공유 변을 보존합니다.
4. 앱에서 **Mesh로 병합** 또는 **Mesh 병합 및 DSF 생성**을 엽니다. 내보낸 프로젝트 폴더와 수정한 `*_terrain.obj`를 지정합니다.
5. **OBJ 검사**로 문제 면과 위치를 확인합니다. 복구 가능한 오류는 **복구한 사본 만들기·사용**으로 새 파일을 만들 수 있습니다. 그다음 병합 또는 DSF 생성까지 진행합니다.
6. 완료 상태와 출력 경로를 확인합니다. 내보낸 OBJ를 파일 관리자에서 지웠거나 옮겼다면 프로젝트 파일 목록을 다시 확인하고 사용할 OBJ를 새로 지정합니다.

## 9. 단축키

숫자·텍스트 입력칸이나 모달에서 입력 중에는 모드·카메라 단축키가 동작하지 않습니다. `1`·`2`·`3`은 키를 누르고 있는 동안 왼쪽 드래그의 동작을 바꾸며 지형을 편집하지 않습니다. 키를 놓으면 해당 카메라 조작이 끝납니다.

| 키 | 동작 |
| --- | --- |
| `W`·`A`·`S`·`D` / 방향키 | 3D 카메라를 위·왼쪽·아래·오른쪽으로 이동 |
| `,` / `.` | 3D 카메라 후진 / 전진 |
| `Q`·`E` / `R`·`F` | 좌우 회전 / 위아래 회전 |
| `+` / `−` | 확대 / 축소 |
| `H` | 선택에 맞춤 |
| `Z` / `X` | 정점 / 면 모드로 전환 |
| `F1` | 탑뷰 ↔ 전환 전 카메라 상태(위치·방향·투영·줌) |
| `1`을 누른 채 왼쪽 드래그 | 화면 이동 |
| `2`를 누른 채 왼쪽 드래그 | 줌: 오른쪽·위로 드래그하면 확대, 반대는 축소 |
| `3`을 누른 채 왼쪽 드래그 | 화면 회전 |
| `M` | Metric / US 단위 전환 |
| `Ctrl/Cmd+A` | 현재 정점 또는 면 모드에서 전체 선택 |
| `Ctrl/Cmd+S` | 저장 |
| `Ctrl/Cmd+Shift+S` | 다른 이름으로 저장 |
| `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | 실행 취소 / 다시 실행 |
| `Enter` / `Esc` | 그리는 경로 확정 / 진행 중인 동작 취소 |
| `Delete` | 정점 모드에서 선택 정점 삭제 및 면 재연결 |

## 10. 문제가 생겼을 때

| 증상 | 확인할 내용 |
| --- | --- |
| **Terrain face has zero area** | 빌드가 면적이 0인 지형 면을 감지한 상태입니다. 콘솔의 마지막 처리 단계와 좌표를 확인합니다. 해당 구간을 와이어프레임으로 살펴보고 마지막 절단·세분화 전후를 비교합니다. |
| **보호 경계의 위치·고도 유지** | OBJ 병합 대상의 외곽이 원본 패치와 맞는지 확인합니다. 편집 프로그램에서 축·단위·원점이 바뀌었는지 OBJ 검사 결과와 비교합니다. |
| **영상·수면 경계를 가로지르는 면** | 로그의 좌표 주변에서 새 면이 물이나 원본 재질 경계와 어떻게 맞닿는지 확인합니다. 재질 경계 일부는 빌드에서 분할할 수 있으며, 검증을 통과하지 못하면 빌드가 중단됩니다. |
| **틈·겹침·T자 접합** | 공유 변 양쪽이 같은 정점에서 연결되는지, 같은 자리에 면이 중복되어 있는지 확인합니다. |
| **선택을 바꾸니 간격·폭이 달라짐** | 새 선택의 수평 크기로 초기값을 다시 추정한 결과입니다. 같은 선택에서는 수동 입력값을 유지합니다. 값이 예상과 다르면 멀리 떨어진 면이 함께 선택됐는지도 확인합니다. |
| **베벨 적용 버튼이 활성화되지 않음** | 현재 선택·설정으로 미리보기를 실행하고 변경 정점 수를 확인합니다. 고도 기울기 변화가 없으면 변경 결과가 없을 수 있습니다. 설정이나 선택이 바뀌면 다시 미리보기해야 합니다. |
| **진행률이 멈추고 오류가 표시됨** | 실패입니다. 콘솔의 마지막 오류를 확인합니다. 성공한 경우에는 완료 상태와 실제 출력 경로가 표시됩니다. |
| **X-Plane에서 변경이 안 보임** | 완료 창에 표시된 DSF가 실제 사용 중인 시너리의 파일인지, 해당 Ortho 팩이 활성화되어 있는지, 더 높은 우선순위의 기본 메시가 덮고 있는지 확인합니다. |
