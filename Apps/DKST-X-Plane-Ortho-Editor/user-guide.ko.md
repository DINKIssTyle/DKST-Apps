# DKST X-Plane Ortho Editor 사용자 매뉴얼

[기능 소개](./README.ko.md) · [English user guide](./user-guide.en.md) · 기준 버전 0.14.0

## 1. 첫 작업 시작하기

1. **라이브러리**에서 X-Plane 시너리를 탐색하려면 환경설정에서 X-Plane 설치 폴더를 지정합니다. 원본 메시가 시너리와 다른 위치에 있다면 Ortho4XP 원본 폴더도 등록합니다.
2. 별도 타일로 작업하려면 **작업 폴더 → 작업 폴더 열기**에서 Ortho 타일 폴더를 선택합니다. 편집 데이터가 들어 있는 타일은 `dkst`를 포함한 타일 폴더 전체를 엽니다.
3. 왼쪽 목록에서 타일을 선택합니다. 지도에서 필요한 범위를 지정하고 **작업 영역**으로 보거나 **전체 타일**로 전환합니다.
4. **인앱 편집**을 열고 정점 또는 면을 선택합니다. 편집을 마치면 **저장**을 누릅니다. X-Plane에서 사용할 결과가 필요하면 **DSF 생성**까지 실행합니다.

Ortho4XP `.mesh`만 있는 폴더에서도 지형 편집과 Mesh 저장을 할 수 있습니다. 영상 표시와 DSF 생성에는 타일에 맞는 기존 시너리 자원이 필요합니다.

## 2. 화면과 카메라

| 컨트롤 | 동작 |
| --- | --- |
| **TOP** | 지형을 위에서 내려다봅니다. 활주로 방향이나 작업 경계를 확인할 때 사용합니다. |
| **정투영 / 원근법** | 정투영은 거리에 따른 크기 변화가 없고, 원근법은 앞뒤 깊이를 드러냅니다. |
| **Y축 배율** | 화면에서만 지형의 높낮이를 과장합니다. 고도 라벨·입력·저장 값은 실제 미터 단위를 사용합니다. 되돌리기 아이콘으로 1×로 복원합니다. |
| **메시 / 텍스처 / 와이어프레임 / 수면** | 표시 레이어를 전환합니다. 텍스처를 끄면 지형의 주름이나 음영을 확인하기 쉽고, 와이어프레임은 면 연결을 보여 줍니다. |
| **선택에 맞춤** | 선택한 정점이나 면이 보기 안에 들어오도록 맞춥니다. 단축키는 `H`입니다. |

3D 뷰에서 우클릭 드래그는 시점을 회전하고, `Space`와 함께 드래그하면 화면을 이동합니다. 휠 확대·축소는 커서 아래 지점을 기준으로 합니다. 환경설정에서 커서 아래 메시 지점을 회전 중심으로 사용하거나, 그 동작을 선택 영역 위에서만 사용하도록 설정할 수 있습니다.

## 3. 선택과 고도 편집

1. **모드**에서 **정점** 또는 **면**을 고릅니다. 면 고도 편집은 면을 구성하는 공유 정점을 움직이므로, 해당 정점을 공유하는 이웃 면도 함께 바뀝니다.
2. **선택** 도구에서 **브러시**, **사각**, **다각**, **클릭** 중 하나를 고릅니다. `Shift`로 추가하고 `Ctrl` 또는 `Cmd`로 제외할 수 있습니다. 브러시에서는 `[`·`]`로 크기를 조절합니다.
3. 다각형은 점을 세 개 이상 찍은 뒤 우클릭이나 `Enter`로 확정합니다. 시작점에 가까이 가서 스냅된 상태로 클릭해도 닫힙니다.
4. 속성 카드에서 고도를 지정하거나 **평탄화**로 선택 정점을 선택 고도의 중앙값에 맞춥니다. **고도 라벨**을 켜면 선택 범위의 동·서·남·북·중앙 고도를 확인할 수 있습니다.
5. **Y축 이동 핸들**을 켜고 녹색 화살표를 드래그해 고도를 조절합니다. `Ctrl`은 0.1m, `Shift`는 1m 단위로 움직입니다.
6. 주변도 부드럽게 움직이려면 속성 카드의 **소프트 셀렉션**을 켜고 영향 범위(m)를 지정합니다. 직접 선택한 곳에서 멀어질수록 영향이 약해지며, 뷰포트에서 영향 범위를 확인할 수 있습니다.

선택을 해제하려면 뷰포트 왼쪽 위 요약 카드 아래의 **선택 취소**를 누릅니다. 나중에 다시 쓸 선택은 오른쪽 **셀렉션 매니저**에서 이름을 붙여 저장합니다. 저장된 항목의 종류는 정점·면 아이콘으로 구분하며 다시 선택, 이름 변경, 선택 내용 갱신, 삭제가 가능합니다. 타일을 저장하면 셀렉션도 프로젝트에 포함됩니다.

## 4. 면 연결 편집

### 칼

1. **칼**을 선택하고 뷰포트에서 절단 경로의 점을 차례로 클릭합니다. 점선과 교차점으로 다음 구간을 미리 봅니다.
2. 열린 절단선은 우클릭 또는 `Enter`로 확정합니다. 닫힌 경로는 점을 세 개 이상 찍고 시작점에 스냅된 상태에서 클릭합니다. `Esc`는 그리는 중인 경로를 취소합니다.
3. **정점 스냅**을 켜면 가까운 메시 정점을 절단 경로에 사용합니다. 시작점 스냅은 이 옵션과 별도로 항상 작동합니다.
4. 절단선이 앞선 구간과 교차하거나 겹쳐 빨간색으로 보이면 끝점을 옮깁니다. 절단 후 정점 모드에서는 경계 정점이 선택됩니다. 면 모드에서는 분할된 면이 기존 선택에서 빠집니다.

### 영역 세분화

1. **영역 세분화**를 열고 대상 면을 선택합니다. 사각형이나 다각형으로 고를 때도 세분화는 선택 면의 기존 경계를 따릅니다.
2. **정점 간격(m)**을 입력하고 **세분화 미리보기**를 누릅니다. 파란 선은 바뀌는 연결, 주황색 선은 최소각이 15° 미만인 삼각형입니다.
3. **같은 평면의 삼각형 연결 개선**을 켜면 선택 영역의 평평한 부분에서 내부 대각선을 다시 배치합니다. 원래 고도 표면을 기준으로 세분화하며, 공유 변을 나눌 때는 이웃 면에도 같은 정점을 연결합니다.
4. 예상 정점과 삼각형 수를 확인하고 **세분화 적용**을 누릅니다. 적용은 한 번에 실행 취소할 수 있습니다. 보호 경계가 있는 구간은 목표 간격에 도달하기 어려울 수 있습니다.

### N-gon과 정점 삭제

- 여러 인접 면을 선택하고 **선택 면 합치기 / N-gon 만들기**를 누르면 외곽을 유지하면서 내부 연결을 단순화합니다. 내부 정점이 사라지면 지형 형상도 달라질 수 있으므로 단면이나 와이어프레임을 확인합니다.
- **N-gon 전체 선택**을 누르거나 개별 N-gon을 고릅니다. 선택이 N-gon으로만 구성되면 **삼각형으로 변환**을 사용할 수 있습니다. 변환은 기존 정점을 사용하며, 같은 평면에서 삼각형이 한 꼭짓점에 몰리는 경우 내부 연결을 개선합니다. 정점 밀도를 높이려면 이어서 **영역 세분화**를 적용합니다.
- 정점 모드에서 **선택 정점 삭제 · 면 재연결**을 실행하면 선택한 내부 정점을 제거하고 주변 면을 다시 연결합니다. 작업 경계나 수면 접점 등 보호된 연결은 편집할 수 없습니다.

## 5. 지형 브러시

| 도구 | 사용법 |
| --- | --- |
| **높낮이** | 지름·경도·강도를 지정하고 지형 위를 드래그해 고도를 조절합니다. 고도 동작과 변화 속도는 옵션 카드에서 설정합니다. |
| **지형 고르기** | 주변 고도 차이를 부드럽게 연결합니다. 경사 전환부에서는 작은 강도로 시작해 와이어프레임과 음영을 함께 확인할 수 있습니다. |
| **칠** | 먼저 지형 위에 마스크를 칠하거나 지웁니다. 범위와 강도를 확인한 다음 고도 작업을 적용합니다. 큰 삼각형 내부에도 마스크를 칠할 수 있습니다. |

대상을 제한하려면 정점이나 면을 먼저 선택하고 브러시 옵션에서 선택에만 적용하도록 설정합니다. 고도 브러시의 자동 세분화는 브러시 자취 주변에 필요한 제어점을 추가합니다. 스트로크 도중 `Esc`를 누르면 진행 중인 변경이 취소됩니다.

## 6. Runway Slope

1. 단면으로 편집할 정점이나 면을 선택하고 **Runway Slope**를 누릅니다.
2. 지형 위에서 시작점과 끝점을 클릭합니다. 화살표 방향을 확인하고 필요하면 **방향 뒤집기**를 누른 뒤 **단면 열기**를 선택합니다.
3. 단면은 시작점에서 끝점 순으로 왼쪽에서 오른쪽으로 표시합니다. 가로축은 거리, 세로축은 고도이며 단위는 미터입니다.
4. 점이나 엣지를 상하로 드래그하거나 고도를 입력합니다. 빈 곳을 드래그하면 여러 점을 선택할 수 있고 `Shift`로 추가, `Ctrl/Cmd`로 제외합니다. **라인업 (정렬)**은 선택한 양 끝점의 고도를 기준으로 그 사이 점을 직선상에 배치합니다.
5. **소프트 브러시**는 반경 안의 단면을 가중치에 따라 상하로 움직입니다. 반경·경도·강도를 지정할 수 있습니다. 더 많은 제어점이 필요하면 단면의 **칼**로 원하는 거리에서 면을 나눕니다.
6. **레퍼런스 이미지**를 불러와 위치, 가로·세로 크기, 투명도를 조절할 수 있습니다. **두 점으로 보정**에서는 이미지의 두 점에 실제 거리·고도를 지정해 맞춥니다.
7. 변경 지형 미리보기를 확인하고 **고도 적용**을 누릅니다. 적용 전 취소하면 단면에서 만든 고도 변경과 절단이 폐기됩니다.

## 7. 저장, 프로젝트 보관, DSF 생성

**저장**은 편집 상태와 전체 타일의 Mesh 결과를 기록합니다. **다른 이름으로 저장**은 작업을 별도 Ortho 패키지로 분기할 때 사용합니다. 편집 결과를 옮기거나 보관하려면 시너리 리소스와 `dkst`를 포함해 Ortho 타일 폴더 전체를 복사합니다.

| 폴더 또는 파일 | 내용 |
| --- | --- |
| `dkst/project.json` | Ortho 패키지의 프로젝트 정보 |
| `dkst/tiles/<좌표>/source/` | 작업 기준 Mesh 및 해당하는 경우 기준 DSF |
| `dkst/tiles/<좌표>/saved/`, `recovery/` | 저장한 편집 상태 및 자동 복구 데이터 |
| `dkst/tiles/<좌표>/exports/`, `builds/` | OBJ 내보내기와 빌드 결과·보고서 |
| `dkst/tiles/<좌표>/backups/dsf/` | DSF 교체 전 백업 |

### X-Plane에 반영하기

1. **인앱 편집** 상단의 **DSF 생성**을 누릅니다. 원본 Ortho 시너리 폴더가 맞는지 확인합니다. Mesh 단독 작업이라면 해당 타일의 기존 DSF, `terrain`, `textures`, Ortho4XP cfg가 있는 폴더를 지정합니다.
2. 생성 중에는 진행률과 콘솔을 확인합니다. 완료 시 실제 DSF 경로와 백업 경로가 표시됩니다. 생성한 DSF는 시너리의 `Earth nav data` 아래 정상 타일 파일명으로 반영됩니다.
3. X-Plane에서 시너리를 다시 로드해 편집한 구간을 확인합니다. 지형은 타일의 실제 편집 결과를 사용하며, 앱의 Y축 배율은 X-Plane에 전달되지 않습니다.

이 기능은 기존 Ortho DSF를 기준으로 지형을 갱신합니다. 최초 DSF를 Mesh만으로 생성하거나 영상 다운로드, 새 해안선·수심 생성을 수행하는 경우에는 별도의 Ortho4XP 작업이 필요합니다.

### 백업에서 다시 시작하기

오른쪽 **DSF 백업**에서 현재 DSF 또는 이전 백업을 고르고 **선택한 DSF로 편집**을 누릅니다. 앱은 선택한 버전의 실제 지형을 기준으로 엽니다. 그 상태에서 DSF를 생성하면 현재 정상 DSF가 새로 백업되고 편집 결과가 정상 파일명에 반영됩니다.

## 8. 외부 도구에서 OBJ 편집하기

1. **외부 도구 편집**에서 작업 영역을 정한 다음 **OBJ로 내보내기**를 실행합니다. 여러 타일을 내보냈다면 편집할 타일의 OBJ를 확인합니다.
2. Blender 등에서 지형 OBJ를 엽니다. 좌표는 로컬 미터 단위이고 X는 동쪽, Y는 위쪽, Z는 남쪽입니다. 원점과 배율을 유지하며, 내보낸 `project.json`, MTL, 텍스처 및 기준 파일의 상대 경로를 유지합니다.
3. 지형 OBJ를 편집합니다. 패치 외곽의 보호 정점은 위치와 높이를 유지하고, 수면 경계와 공유 변을 보존합니다.
4. 앱에서 **Mesh로 병합** 또는 **Mesh 병합 및 DSF 생성**을 엽니다. 내보낸 프로젝트 폴더와 수정한 `*_terrain.obj`를 지정합니다.
5. **OBJ 검사**로 문제 면과 위치를 확인합니다. 복구 가능한 오류는 **복구한 사본 만들기·사용**으로 새 파일을 만들 수 있습니다. 그다음 병합 또는 DSF 생성까지 진행합니다.
6. 완료 상태와 출력 경로를 확인합니다. 내보낸 OBJ를 파일 관리자에서 지웠거나 옮겼다면 프로젝트 파일 목록을 다시 확인하고 사용할 OBJ를 새로 지정합니다.

## 9. 단축키

| 키 | 동작 |
| --- | --- |
| `W`·`A`·`S`·`D` / 방향키 | 3D 카메라를 위·왼쪽·아래·오른쪽으로 이동 |
| `,` / `.` | 3D 카메라 후진 / 전진 |
| `Q`·`E` / `R`·`F` | 좌우 회전 / 위아래 회전 |
| `+` / `−` | 확대 / 축소 |
| `H` | 선택에 맞춤 |
| `Ctrl/Cmd+A` | 현재 정점 또는 면 모드에서 전체 선택 |
| `Ctrl/Cmd+S` | 저장 |
| `Ctrl/Cmd+Shift+S` | 다른 이름으로 저장 |
| `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` | 실행 취소 / 다시 실행 |
| `Enter` / `Esc` | 그리는 경로 확정 / 진행 중인 동작 취소 |
| `Delete` | 정점 모드에서 선택 정점 삭제 및 면 재연결 |

## 10. 문제가 생겼을 때

| **Terrain face has zero area** | 빌드가 면적이 0인 지형 면을 감지한 상태입니다. 콘솔의 마지막 처리 단계와 좌표를 확인합니다. 해당 구간을 와이어프레임으로 살펴보고 마지막 절단·세분화 전후를 비교합니다. |
| **보호 경계의 위치·고도 유지** | OBJ 병합 대상의 외곽이 원본 패치와 맞는지 확인합니다. 편집 프로그램에서 축·단위·원점이 바뀌었는지 OBJ 검사 결과와 비교합니다. |
| **영상·수면 경계를 가로지르는 면** | 로그의 좌표 주변에서 새 면이 물이나 원본 재질 경계와 어떻게 맞닿는지 확인합니다. 재질 경계 일부는 빌드에서 분할할 수 있으며, 검증을 통과하지 못하면 빌드가 중단됩니다. |
| **틈·겹침·T자 접합** | 공유 변 양쪽이 같은 정점에서 연결되는지, 같은 자리에 면이 중복되어 있는지 확인합니다. |
| **진행률이 멈추고 오류가 표시됨** | 실패입니다. 콘솔의 마지막 오류를 확인합니다. 성공한 경우에는 완료 상태와 실제 출력 경로가 표시됩니다. |
| **X-Plane에서 변경이 안 보임** | 완료 창에 표시된 DSF가 실제 사용 중인 시너리의 파일인지, 해당 Ortho 팩이 활성화되어 있는지, 더 높은 우선순위의 기본 메시가 덮고 있는지 확인합니다. |
